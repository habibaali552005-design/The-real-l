# خطة: تكامل فيسبوك + استيراد ذكي داخل لوحة الإدارة

**الموقع نفسه مش هيتغير خالص** — كل الشغل جوّه تبويبات جديدة في `/admin` بس.

## اللي محتاج أوضحه قبل التنفيذ (قيود تقنية حقيقية)

1. **فيسبوك مش بيسمح بسحب منشورات صفحة إلا عن طريق Graph API الرسمي**، وده بيتطلب:
   - إنشاء تطبيق على developers.facebook.com
   - ربط الصفحة بيه واستخراج **Page Access Token** طويل الأمد
   - صلاحيات: `pages_read_engagement` + `pages_manage_posts` (متاحة لصاحب الصفحة من غير App Review)

   السكرابينج المباشر (بدون توكن) بيرجع صفحة تسجيل دخول فاضية — مفيش طريقة تانية شغالة.

2. **الـ Auto Sync الفوري** (webhook لحظة النشر) بيتطلب اشتراك Webhooks في نفس التطبيق. البديل الأبسط: **polling كل ٥-١٥ دقيقة** بيجيب المنشورات الجديدة. هبدأ بالـ polling وهضيف الـ webhook بعدين.

3. **تعديل الصور بالـ AI** (خلفية استوديو، إزالة خلفية، تحسين جودة، توسيع، إلخ) هيستخدم `google/gemini-3.1-flash-image` من Lovable AI (متاح فوراً، مفيش مفاتيح خارجية).

## المرحلة ١ — البنية التحتية (هعملها الأول)

**جداول جديدة:**

- `product_images` — صور متعددة لكل منتج + ترتيب + غلاف
- `facebook_connections` — الـ Page ID + Access Token (مشفّر) + auto_sync on/off + آخر sync
- `facebook_post_links` — ربط post_id بـ product_id (لمنع التكرار)
- `sync_logs` — سجل كل عملية sync (نجاح/فشل/تكرارات)

توسيع `products` بأعمدة: `short_description`, `specifications` (jsonb), `colors` (text[]), `sizes` (text[]), `tags` (text[]), `seo_title`, `seo_description`, `is_published`, `manually_edited_fields` (text[] لمنع overwrite بعد التعديل اليدوي).

**تبويب جديد في `/admin`:** "فيسبوك" فيه:

- زر Connect Facebook (يفتح OAuth) + عرض الصفحة المربوطة
- تبديل Auto Sync
- Sync Now / Import All / Disconnect
- جدول Sync History

## المرحلة ٢ — Facebook OAuth + جلب المنشورات

- Server route `/api/facebook/oauth/callback` — يستقبل الكود، يبدله بـ Page Access Token طويل الأمد، يخزنه.
- Server function `syncFacebookPosts` — يجيب آخر ٥٠ منشور، يفلتر اللي فيه صور + سعر.
- Cron كل ١٠ دقايق (pg_cron → server route) لما Auto Sync = ON.

## المرحلة ٣ — كشف التكرار (Duplicate Detection)

بالترتيب: (1) Facebook post ID → موجود؟ اربطه بالمنتج نفسه. (2) hash للصورة الأولى. (3) تشابه العنوان بالـ AI (Gemini embedding). لو ≥٨٥٪ تشابه → ربط بدل إنشاء.

## المرحلة ٤ — الاستخراج الذكي بالـ AI

لكل منشور جديد → استدعاء Gemini بالنص + الصور → JSON فيه: title, price, description, specs, colors, sizes, category (من قائمة الأقسام الموجودة), keywords, tags.

## المرحلة ٥ — محرر الصور بالـ AI

في صفحة تعديل المنتج، لكل صورة أزرار: إزالة خلفية / خلفية استوديو / خلفية lifestyle / تحسين جودة / توسيع / اقتصاص / تدوير / علامة مائية. كل عملية تستدعي Gemini image editing وتحفظ نسخة جديدة **مع الاحتفاظ بالأصلية**.

## المرحلة ٦ — قواعد حماية التعديل اليدوي

أي حقل تعديليه يدوياً يتسجل في `manually_edited_fields` → الـ sync ميلمسوش تاني. لو فيه conflict حقيقي، يظهر في تبويب "تعارضات" باختيارات: Keep Website / Keep Facebook / Merge.

---

## اللي محتاجاه منك قبل ما أبدأ

**سؤال ١: صلاحيات فيسبوك.** عشان أشغّل الاستيراد التلقائي، لازم تعملي تطبيق على developers.facebook.com وتديني App ID + App Secret. أقدر أوريكي الخطوات بالصور خطوة خطوة. هل تمام؟ أو تفضلي حل بديل: **زرار "استيراد بالجملة"** — بتلصقي نصوص المنشورات + بتسحبي الصور من الجهاز، والـ AI يستخرج كل حاجة تلقائي (نفس النتيجة، بدون تعقيد فيسبوك).

**سؤال ٢: حجم المرحلة الأولى.** الخطة كاملة كبيرة جداً (٦ مراحل). أبدأ بإيه الأول؟

- (أ) صور متعددة لكل منتج + محرر AI للصور (أهم حاجة للمظهر)
- (ب) استيراد بالجملة بالـ AI (أسرع طريقة تنزلي بيها منتجاتك دلوقتي)
- (ج) ربط فيسبوك الكامل (بياخد وقت أطول ومحتاج App)

قوليلي الإجابات وأبدأ فوراً في المرحلة اللي تختاريها.
